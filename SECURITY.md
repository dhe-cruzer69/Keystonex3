# Security Policy

## Supported versions
Only the latest tag on `main` receives security fixes.

## Reporting a vulnerability
Report privately via GitHub Security Advisories on this repository (Security tab,
"Report a vulnerability"). Do not open a public issue.

Include affected version or commit SHA, reproduction steps and impact. You will
get an acknowledgement within 72 hours.

## Disclosure
Coordinated disclosure, 90 days or earlier if a fix ships first.

## Baseline controls
Dependabot updates, dependency audit gating in CI, SHA-pinned Actions,
least-privilege workflow tokens, and required status checks on `main`.
